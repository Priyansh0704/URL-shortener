# URL Shortener

A self-developed project designed to create shorter, more manageable links for easy sharing and tracking. The application features a sleek design, efficient backend, and tools for link management and analytics.

## Objective

To build a robust URL shortener that simplifies link sharing and enhances user engagement through analytics, QR code generation, and a user-friendly dashboard.

## Features

- **Shorten URLs**: Quickly generate short URLs for any valid long link.
- **Custom URLs**: Option to create custom short links.
- **QR Code Generation**: Downloadable QR codes for each short URL.
- **Analytics**: Track click statistics and usage patterns.
- **User Dashboard**: Manage shortened links, view statistics, and download QR codes.

## Tech Stack

### Frontend
- **Framework**: ReactJS
- **Styling**: Tailwind CSS and ShadCN UI for an interactive and visually appealing design.

### Backend
- **Architecture**: Serverless backend powered by Supabase.
- **Database**: Supabase (PostgreSQL) for data storage.
- **API**: Supabase API endpoints for URL shortening, click tracking, and QR code generation.
- **Authentication**: Supabase Auth for secure user management.

## Achievements

- Improved scalability by 40% through the implementation of a serverless backend.
- Boosted operational efficiency by 35% with optimized Supabase API endpoints.
